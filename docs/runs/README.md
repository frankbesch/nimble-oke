# Measured runs

Each file here is the receipt of one run of `scripts/run_measured.sh` against
a real OCI account. A receipt records the date, region, shape, image,
Kubernetes version, time per phase, billable time, estimated cost with its
rate basis, benchmark numbers, and the teardown result.

A receipt holds no OCIDs, no IP addresses, and no key. Raw step logs stay out
of git.

No receipt is committed yet.
