path produced a working cluster. One `VM.GPU.A10.1` node, one NVIDIA A10,
`nvcr.io/nim/meta/llama3-8b-instruct:1.0.3`, the chart in `helm/` at 0.1.0,
Kubernetes v1.34.1, region `us-phoenix-1`. Run by the owner from a local
terminal:

```bash
scripts/run_measured.sh --key-file ~/.ngc-key docs/runs/2026-10-01-fixed-2
```

Scope: provision, deploy, one readiness check, five benchmark requests,
teardown, and a clean check. Autoscaling is a separate run.

## Teardown

Three attempts, the last one clean:

1. The GPU node pool was deleted and confirmed. The system node pool's work
   request ended SUCCEEDED after 21 minutes, but the pool still read
   `DELETING` on the single state check, so the attempt stopped without
   deleting the cluster.
2. The delete call returned 409 Conflict because the pool was still
   `DELETING`.
3. The pool was gone. The cluster, subnets, and security lists were deleted
   and confirmed.

At no point did the script delete the cluster or report clean while a node
pool was unconfirmed. The kit now polls the state after a work request ends,
and treats a 409 on a deleting resource as a reason to wait.

A separate read of the compartment after the run found no cluster, no node
pool, no instance, no block or boot volume, and no load balancer. The VCN
existed before the run and was left in place by design.

## The attempt before this one

An earlier attempt the same day failed 12 minutes in. Node pool creation
returned 400: "The service subnets cannot be used by node pools." The cluster
had been created with the worker subnet also set as its service load-balancer
subnet. The failure trap deleted the cluster, teardown removed the subnets and
security lists, and the clean check passed. No GPU node was created. The fix
was to stop assigning a service load-balancer subnet, since the chart's
Service is ClusterIP.

## What this run does not show

- Autoscaling. The GPU pool was fixed at one node.
- Repeatability. This is one run.
- Performance under load or with streaming.
- The actual bill.
- The zero-grace teardown and the state polling, both added after this run.
- Regions other than Phoenix. The GPU node image is pinned to it.
