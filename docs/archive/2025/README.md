# Archive: October 2025 working notes

These files are planning and analysis notes from the first build in October
2025. They are kept for the record. They are not measurements, and several
describe scripts and timings that were never run on a cluster.

Their prices and shapes were corrected on 2026-10-01. Everything else is as
written in 2025.

For current status and measured results, see the [README](../../../README.md)
and the receipts in [docs/runs/](../../runs/).
